Start with the repository's implementation guides:

- [Architecture overview](https://github.com/gustavommcv/mangabound/blob/main/docs/architecture.md): layers, allowed dependencies, conversion flow, persistence, and extension points.
- [CONTRIBUTING](https://github.com/gustavommcv/mangabound/blob/main/CONTRIBUTING.md): setup, formatting, linting, type checking, fixture-based tests, Storybook, packaged E2E, and the exact-commit remote CI gate.
- [Architecture decision records](https://github.com/gustavommcv/mangabound/tree/main/docs/adr): the reasons and tradeoffs behind accepted decisions.

Domain rules do not depend on Electron or React. Adapters implement the application's ports; the sandboxed renderer uses the validated preload bridge instead of accessing files or processes directly.

## Contributing to this site

See [website/README.md](https://github.com/gustavommcv/mangabound/blob/main/website/README.md) for the independent documentation checks and publication policy. GIFs and screenshots follow [the media guide](https://github.com/gustavommcv/mangabound/blob/main/website/MEDIA.md).

Update both languages when changing a user task. Verify button labels and behavior against the released app; visual media illustrates the instructions but does not replace them.
