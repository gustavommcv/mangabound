Download from the [official release page](https://github.com/gustavommcv/mangabound/releases). Expand **Assets** and choose your operating system and processor architecture. Alpha releases are marked **Pre-release**.

<Tabs>
<TabItem label="Windows">

### Windows x64

- Choose the **.Setup.exe** installer for a normal installation.
- Alternatively, extract the **win32-x64 .zip** and run the executable inside the extracted folder.

The alpha installer is not commercially signed. SmartScreen may warn about it. Only proceed if you expected this download and obtained it from the official release page; do not disable Windows security globally.

</TabItem>
<TabItem label="macOS">

### macOS Apple Silicon

Download the **darwin-arm64 .zip**, extract it, and move **Mangabound.app** to **Applications**. There is currently no Intel Mac package.

The alpha app is not notarized. If macOS blocks an app you trust, first try opening it, then use **System Settings → Privacy & Security → Open Anyway** if available. Follow [Apple's guidance](https://support.apple.com/en-lamr/102445); do not disable Gatekeeper globally.

</TabItem>
<TabItem label="Linux">

### Linux x64

Choose the package for your distribution:

| Distribution                           | Asset          |
| -------------------------------------- | -------------- |
| Debian / Ubuntu and compatible systems | `.deb`         |
| Fedora and compatible systems          | `.rpm`         |
| Arch Linux and compatible systems      | `.pkg.tar.zst` |

Open a terminal in the folder containing your download and use the command for your distribution below. Replace `package.deb`, `package.rpm`, or `package.pkg.tar.zst` with the exact name of the file you downloaded. Keep its original filename; you do not need to rename it.

**[Debian / Ubuntu](https://documentation.ubuntu.com/project/contributors/bug-fix/install-built-packages/)**

```bash
sudo apt install ./package.deb
```

**[Fedora](https://dnf.readthedocs.io/en/latest/command_ref.html#install-command)**

```bash
sudo dnf install ./package.rpm
```

**[Arch Linux](https://man.archlinux.org/man/pacman.8.en)**

```bash
sudo pacman -U ./package.pkg.tar.zst
```

Then open **Mangabound** from your application menu. Use `sudo` only to install it, not to run the app.

</TabItem>

## Check your download

Each release has a `SHA256SUMS` file that lists the checksum of every other file of the release. Put it in the folder you downloaded to and run `sha256sum -c SHA256SUMS` (`shasum -a 256 -c SHA256SUMS` on macOS). On Windows, `Get-FileHash <file>` in PowerShell prints the value to compare with the line of that file. A file that is not in the folder is reported as missing, and one that does not match is reported as failed.

The checksums show that a download is what the release collected and that it arrived whole. They do not show where the files were built, and there is no build attestation yet. Releases before alpha.11 have no `SHA256SUMS`.

## If installation fails

Check that the download matches your system and architecture. Never download an unofficial replacement executable to bypass a toolchain verification error.

## Reporting a problem

[Open an issue](https://github.com/gustavommcv/mangabound/issues) and include the release version, your operating system, what you were trying to do and what happened. For a crash or a failed conversion, include the exact error message.
