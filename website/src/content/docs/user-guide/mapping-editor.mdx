The mapping editor decides which local chapters belong to each volume. All three **Chapters from** tabs work on the same mapping; you can edit a suggestion just as you can build volumes from scratch.

## File names

If names contain volume numbers, **File names** shows a summary of the recognized grouping. It does not infer volume boundaries from typical chapter counts.

Use **Edit chapter mapping** to open manual controls when a summary needs correction. **Start over from the names** restores the initial filename grouping, discarding edits.

## Manual: no online lookup needed

1. Select **Manual**. If no volumes were found in names, this tab opens automatically.
2. Use **Create volume 1** to add the first volume.
3. Select chapters in the chapter list, choose the destination volume, and use **Assign selected**. For consecutive numbered chapters, use **Assign range**.
4. Repeat for the other volumes. Assigning an already placed chapter moves it rather than duplicating it.
5. Resolve the listed issues, then use **Confirm mapping**.

Use the editor's controls to change volume numbers or merge volumes. The undo/redo buttons let you reverse changes.

## The same chapter twice

A folder sometimes holds one chapter from two groups, for example `Ch.0002 [G1]` and `Ch.0002 [G2]`. mangabind cannot choose between the copies: it leaves **all** of them out of the book, and placing one of them in a volume does not change that. The editor therefore lists this as an error, **Chapter 2 is in the folder more than once**, until you remove all but one of the copies from the folder and add the folder again.

If a book is made anyway and something was left out of it, the results say so under the book, for example that chapters with more than one copy, chapters missing inside a volume, chapters with no pages, or links that lead outside the folder were left out. A link in a manga folder is followed only when it leads to a file inside that folder, so that a folder from someone else cannot put a file of yours into a book; to keep such a page, put a copy of the file in the folder.

## Folders whose names are not chapter names

mangabind reads each folder's name for a chapter number. A folder it cannot read (`Omake`, `Ch.004 [GroupA]`, a name in another script with no number) is in no volume and in no book, and the editor cannot place it, since it does not know which chapter it is. The queue row and the editor say so, with the names, under **Folders left out**. Rename the folders to include a chapter number, for example `Ch.005`, and add the folder again. For a library, the queue row names each title with the folders left out of it, and the editor of that title lists them; after renaming, add the library again.

A series kept in a library as a link to a folder is not read either, since mangabind does not follow links to a series. The screen of the library's titles says which folders were left out, by name, above the list; if every folder of the library is a link, its queue row says so instead of asking you to turn grouping off. Put the real folders in the library and add it again.

## Online source: optional suggestions

Choose **Online source**, select MangaDex, enter the title, and press **Search**.

Select the matching work with **Use these volumes**, review the summary, then confirm it or use **Edit chapter mapping**. An online mapping may be incomplete or differ from your edition; verify special and decimal chapters. If the work is absent, use **Manual**.

## Skipping grouping

**Skip grouping** is available where the workflow allows conversion without regrouping. It is disabled in **Create one book for the series** mode because that mode needs mapped volumes for the nested EPUB contents.

The mapping is exchanged with mangabind through its [documented metadata format](https://github.com/gustavommcv/mangabind/blob/main/docs/adr/0010-local-metadata-file.md). You do not need to edit JSON to use the editor.
