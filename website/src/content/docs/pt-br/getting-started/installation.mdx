Baixe pela [página oficial de releases](https://github.com/gustavommcv/mangabound/releases). Expanda **Assets** e escolha seu sistema operacional e arquitetura. Versões alfa aparecem como **Pre-release**.

<Tabs>
<TabItem label="Windows">

### Windows x64

- Escolha o instalador **.Setup.exe** para uma instalação normal.
- Como alternativa, extraia o **.zip win32-x64** e execute o aplicativo dentro da pasta extraída.

O instalador alfa não possui assinatura comercial. O SmartScreen pode mostrar um aviso. Só prossiga se esperava esse download e o obteve na página oficial; não desative a segurança do Windows globalmente.

</TabItem>
<TabItem label="macOS">

### macOS Apple Silicon

Baixe o **.zip darwin-arm64**, extraia e mova **Mangabound.app** para **Applications**. Ainda não há pacote para Mac Intel.

O aplicativo alfa não é notarizado. Se o macOS bloquear um aplicativo em que você confia, primeiro tente abri-lo e depois use **Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim**, se disponível. Siga as [orientações da Apple](https://support.apple.com/en-lamr/102445); não desative o Gatekeeper globalmente.

</TabItem>
<TabItem label="Linux">

### Linux x64

Escolha o pacote da sua distribuição:

| Distribuição                           | Arquivo        |
| -------------------------------------- | -------------- |
| Debian / Ubuntu e sistemas compatíveis | `.deb`         |
| Fedora e sistemas compatíveis          | `.rpm`         |
| Arch Linux e sistemas compatíveis      | `.pkg.tar.zst` |

Instale o arquivo baixado com o gerenciador de pacotes da distribuição. Preserve seu nome original: os separadores de versão e revisão variam conforme o formato.

</TabItem>
</Tabs>

## Confira o download

Cada release tem um arquivo `SHA256SUMS` com o checksum de todos os outros arquivos dela. Coloque-o na pasta onde você baixou e execute `sha256sum -c SHA256SUMS` (`shasum -a 256 -c SHA256SUMS` no macOS). No Windows, `Get-FileHash <arquivo>` no PowerShell mostra o valor para comparar com a linha daquele arquivo. Um arquivo que não está na pasta é informado como ausente, e um que não confere é informado como falho.

Os checksums mostram que o download é o que a release reuniu e que chegou inteiro. Eles não mostram onde os arquivos foram construídos, e ainda não há atestado de build. As releases anteriores à alpha.11 não têm `SHA256SUMS`.

## Se a instalação falhar

Confira se o download corresponde ao sistema e à arquitetura. Não baixe executáveis substitutos não oficiais para contornar um erro de verificação das ferramentas.

## Relatar um problema

[Abra uma issue](https://github.com/gustavommcv/mangabound/issues) e inclua a versão da release, o sistema operacional, o que você tentava fazer e o que aconteceu. Para uma falha ou conversão que não terminou, inclua a mensagem de erro exata.
