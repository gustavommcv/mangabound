## Qual entrada devo adicionar?

| O que você tem                                                 | O que adicionar                                              |
| -------------------------------------------------------------- | ------------------------------------------------------------ |
| Pastas de capítulos ou CBZs separados de capítulos de uma obra | A pasta do mangá que os contém                               |
| Várias pastas de mangá em uma biblioteca                       | A pasta da biblioteca; confira suas obras antes de processar |
| Um volume completo já em CBZ                                   | O próprio CBZ                                                |

Use **Files**, **Folder** ou arraste arquivos e pastas para a fila. Você também pode clicar na área de arquivos para escolher o que adicionar. O Mangabound analisa os capítulos antes de converter e indica quais precisam de revisão.

## Confira um item

Use **Edit volumes** para organizar capítulos em volumes. Uma biblioteca abre a lista de obras, permitindo revisar cada mangá. Remover uma entrada da fila não apaga seus arquivos originais.

Use a ação de detalhes do livro para definir **Series title** ou **Book title**, **Author** e **Language** de cada item. Você pode preencher o autor ou buscá-lo online. Se os nomes das pastas indicarem que o mangá está em outro idioma que não o dos livros, o campo **Language** oferece um botão para usá-lo, como **Use pt-BR**; nada muda até você clicar. Você pode digitar o idioma com qualquer combinação de maiúsculas e minúsculas: os livros sempre são gravados na forma padrão, então `pt-br` vira `pt-BR`. Em uma biblioteca, defina os dados de cada obra.

### Uma capa sua

A mesma página tem **Covers**, com uma linha para cada livro que o item gera. Um livro sem capa própria usa a primeira página, como antes.

- **Choose cover…** escolhe uma imagem para aquele livro; soltar uma imagem na linha faz o mesmo. A imagem pode estar em qualquer lugar e ter qualquer nome: o Mangabound guarda a sua própria cópia, então o original pode ser movido ou apagado depois.
- **Add covers from a folder…** distribui as imagens da pasta entre os livros em ordem de nome: a primeira para o primeiro livro, a segunda para o segundo. Soltar uma pasta, ou várias imagens, na lista faz o mesmo. Uma capa que você escolheu à mão nunca é substituída assim; uma que veio de uma pasta anterior é.
- Cada capa pode ser trocada ou removida na sua linha. As capas ficam lembradas para aquela pasta ou arquivo, e voltam na próxima vez que você o adicionar.

As capas são imagens JPEG, PNG, WebP, GIF ou BMP. **Cut the front cover from a wide image** e **Crop the cover to fill the screen**, nas [opções de conversão](../output-profiles/), valem para elas também. Um PDF não tem capa.

## Os capítulos não têm volume no nome

Você não precisa renomear toda a coleção. Abra o editor: se não houver volumes reconhecidos, ele muda para **Manual** e oferece **Online source** como alternativa opcional. Siga [organização de volumes](../mapping-editor/).

Um CBZ de capítulo adicionado sozinho é considerado um volume completo. Adicione sua pasta para agrupá-lo com os demais.
