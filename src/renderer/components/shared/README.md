# Shared compositions

Small pieces used across screens rather than owned by one of them, each with a story and tests. This includes `Notices` (the dismissible message shown when a saved setting could not be used and what took its place) and `InfoBanner` (the non-dismissible informational status banner used across settings, volume mapping, and library views).

A composition earns a place here when a second screen needs it, with real props, accessible behavior, a story and a test. It is not created ahead of a use.
