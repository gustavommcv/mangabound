# Mangabound v0.1.0-alpha.12

An alpha: the installers are not code-signed. How to install, and what to expect from the system, is in the [installation guide](https://gustavommcv.github.io/mangabound/getting-started/installation/). `SHA256SUMS` checks the downloads.

## Changed

- The window fits beside another app on a small screen, with a minimum width of 640 pixels.
- The user guide has more illustrated examples and Linux installation commands. The README and contributor guides are shorter and easier to navigate.
- Packages include the bundled converters' licenses and dependency notices.
- Custom book titles still name the saved files, even though the updated converter now names files after their inputs by default. Characters unsuitable for filenames use a portable spelling; the title inside the book is unchanged.

## Fixed

- Grouping counts only supported image pages. Results identify unreadable chapter archives and oversized entries that were left out. The queue also names linked series folders that were skipped in a library.
- Cancelling grouping stops before the final archive is published. Invalid metadata ranges are rejected, and scan warnings remain visible even when no chapters are found.
- EPUB navigation has consistent chapter ordering in a combined book, and centered pages use the standard EPUB property.
- Kindle DX output dimensions and the 1920-pixel EPUB width limit for larger Scribe profiles match Kindle Comic Converter 12.
- Conversion checks input sizes and image dimensions before decoding, refuses unusable output names, and does not overwrite an existing book. Saved books keep ordinary file permissions on Linux and macOS.
- **Use the images as they are** with BMP images is refused for EPUB, with a recovery message. Normal BMP conversion and CBZ output remain supported.
- The Arch package uses the same default application icon as the other Linux packages.

## Security

- Conversion follows folder links only when their destination remains inside the selected input.

Bundled: mangabind v0.7.1, mangapress v0.7.3. [Full changelog](https://github.com/gustavommcv/mangabound/compare/v0.1.0-alpha.11...v0.1.0-alpha.12)
