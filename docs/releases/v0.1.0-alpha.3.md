# Mangabound v0.1.0-alpha.3

Mangabound is a desktop app that turns manga you already have — folders of chapters, or `.cbz` files — into books ready for your e-reader.

**This is an alpha.** Expect rough edges: no auto-update yet, and the installers aren't code-signed. See "Known limitations" below before you install.

## What's new since v0.1.0-alpha.2

- **Arch Linux is now a supported platform**, via a direct `.pkg.tar.zst` download — see "Installing" below.
- **A portable Windows build**: unzip and run, no installer, no admin rights needed — an alternative to the Setup wizard for anyone who'd rather not run an installer at all.
- **A settings-save reliability fix.** On Windows, another process briefly holding a lock on the settings file (a real-time antivirus scan, a search indexer) could make a save fail outright instead of just waiting a moment and succeeding. Saves now retry briefly before giving up.
- **Accessibility: focus now moves sensibly between screens.** Moving to a new screen, or starting a conversion, moves keyboard focus to that screen's heading so screen readers and keyboard navigation land somewhere sensible instead of staying wherever focus happened to be before.

## Installing

**Windows:** download `Mangabound-0.1.0-alpha.3.Setup.exe` and run it. The installer is not code-signed, so Windows will identify it as coming from an unrecognized publisher. If you'd rather skip the installer entirely, download the portable `.zip` instead, unzip it anywhere, and run `mangabound.exe` directly — nothing is written outside that folder except your own settings and converted books.

**macOS (Apple Silicon):** download the `.zip`, unzip it, and drag `Mangabound.app` to your Applications folder. The app is not signed or notarized, so macOS will block its first launch by default.

**Debian, Ubuntu, and derivatives:** download the `.deb` and install it with your usual tool, for example:

```text
sudo apt install ./mangabound_0.1.0.alpha.3_amd64.deb
```

**Fedora, RHEL, and derivatives:** download the `.rpm` and install it with your usual tool, for example:

```text
sudo dnf install ./mangabound-0.1.0.alpha.3-1.x86_64.rpm
```

**Arch, and derivatives:** download the `.pkg.tar.zst` and install it with pacman, for example:

```text
sudo pacman -U ./mangabound-0.1.0_alpha.3-1-x86_64.pkg.tar.zst
```

This is a direct download built by this project's own CI, not a submission to the AUR — pacman will resolve and install the app's runtime dependencies from your usual repositories.

## Security prompts

The installers are not code-signed or notarized yet. Windows SmartScreen will warn about an unrecognized publisher, and macOS Gatekeeper will block an unidentified developer by default. We will document the exact prompts and per-app bypass steps after testing the published files; do not disable either operating system's protection globally.

Linux installs through `.deb`, `.rpm`, or pacman are not expected to show an equivalent prompt.

## What's bundled

Mangabound includes two pinned command-line tools; nothing is downloaded after installation:

- **[mangabind](https://github.com/gustavommcv/mangabind) v0.4.0** — groups chapters into volumes.
- **[mangapress](https://github.com/gustavommcv/mangapress) v0.5.0** — converts a volume for your e-reader.

Both are checksum-verified at build time and again the first time the app runs.

## Known limitations

- No automatic updates; download and install each new release manually.
- No code signing or notarization on any platform.
- macOS builds support Apple Silicon only, not Intel Macs.
- No AppImage in this alpha.
- The Arch package is a direct download; there is no AUR submission yet.

## Reporting a problem

Please [open an issue](https://github.com/gustavommcv/mangabound/issues) and include your operating system, what you were trying to do, and what happened. For a crash or failed conversion, include the exact error message.
