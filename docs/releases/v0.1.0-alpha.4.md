# Mangabound v0.1.0-alpha.4

Mangabound is a desktop app that turns manga you already have — folders of chapters or `.cbz` files — into books ready for your e-reader.

**This is an alpha.** There is no auto-update yet, and the installers are not code-signed. See "Known limitations" before installing.

## What's new since v0.1.0-alpha.3

- **One EPUB for a whole series.** In mangapress options, check "Bind the whole series as one volume" to combine all mapped volumes into one EPUB. The table of contents has expandable volumes with their chapters underneath. This option is EPUB-only for now; selecting it while using CBZ or PDF switches the output to EPUB and explains why.
- **Restore individual settings.** Changed options are marked and have their own restore-default control, alongside the existing reset-all action.
- **Remember the sharing network interface.** When you choose Ethernet, a VPN, or another interface for your OPDS catalog, Mangabound remembers that choice for the next time it is available.

## Installing

**Windows:** download `Mangabound-0.1.0-alpha.4.Setup.exe` and run it. The installer is not code-signed, so Windows may identify it as coming from an unrecognized publisher. If you prefer not to run an installer, download the portable `.zip`, unzip it, and run `mangabound.exe` directly.

**macOS (Apple Silicon):** download the `.zip`, unzip it, and drag `Mangabound.app` to your Applications folder. The app is not signed or notarized, so macOS may block its first launch.

**Debian, Ubuntu, and derivatives:** download the `.deb` and install it with your usual tool, for example:

```text
sudo apt install ./mangabound_0.1.0.alpha.4_amd64.deb
```

**Fedora, RHEL, and derivatives:** download the `.rpm` and install it with your usual tool, for example:

```text
sudo dnf install ./mangabound-0.1.0.alpha.4-1.x86_64.rpm
```

**Arch, and derivatives:** download the `.pkg.tar.zst` and install it with pacman, for example:

```text
sudo pacman -U ./mangabound-0.1.0_alpha.4-1-x86_64.pkg.tar.zst
```

This is a direct download built by this project's CI, not a submission to the AUR. Pacman resolves the app's runtime dependencies from your usual repositories.

## Security prompts

The Windows installer is not code-signed, and the macOS app is not signed or notarized. Both operating systems may show a security warning. We will document the exact prompts and per-app steps after testing the published files; do not disable either operating system's protection globally.

## What's bundled

Mangabound includes two pinned command-line tools; nothing is downloaded after installation:

- **[mangabind](https://github.com/gustavommcv/mangabind) v0.5.0** — groups chapters into volumes and can bind the whole series into one `.cbz` for conversion.
- **[mangapress](https://github.com/gustavommcv/mangapress) v0.6.0** — converts for your e-reader and builds the nested EPUB table of contents.

Both are checksum-verified at build time and again the first time the app runs.

## Known limitations

- Combining the whole series into one book supports EPUB only, not CBZ or PDF.
- No automatic updates; download and install each new release manually.
- No code signing or notarization on any platform.
- macOS builds support Apple Silicon only, not Intel Macs.
- No AppImage in this alpha.
- The Arch package is a direct download; there is no AUR submission yet.

## Reporting a problem

Please [open an issue](https://github.com/gustavommcv/mangabound/issues) and include your operating system, what you were trying to do, and what happened. For a crash or failed conversion, include the exact error message.
