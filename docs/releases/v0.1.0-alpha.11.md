# Mangabound v0.1.0-alpha.11

An alpha: the installers are not code-signed. How to install, and what to expect from the system, is in the [installation guide](https://gustavommcv.github.io/mangabound/getting-started/installation/). `SHA256SUMS` checks the downloads.

## Before you update

- **Every conversion changes.** mangapress goes from 0.6.0 to 0.7.2 and makes pages the way Kindle Comic Converter 12 does. In KOReader, EPUB pages are no longer stretched (they came out 11 to 15% wider than drawn). Convert again the books you made before.
- **Linux:** the `.deb`, `.rpm` and Arch packages of alpha.10 could not convert for a normal user. Fixed; install this one over it.
- **Windows:** unsaved books and attached covers move from the installer's folder to `%LOCALAPPDATA%\Mangabound Data` on the first start. Nothing is replaced.
- **Sharing** now serves every book that is ready to save, old unsaved conversions included. They cannot be deleted while shared.

## Added

- The options of mangapress 0.7: page layout in five sections, image options in two, a Cover section, **Use the images as they are**, and **Name the book .epub** for a Kobo. Color now follows the device.
- A cover of your own for each book, on the details page.
- The results say what mangapress noticed (small pages, pages converted already, files that are not images), once for each kind.
- **Use pt-br** on the details page when the folder names declare a language. Language tags are written in BCP 47 form (`pt-BR`).
- Chapter folders left out because their names are not chapter names (`Omake`, `Ch.004 [GroupA]`) are named in the queue and the editor, for a folder and for each title of a library.
- A `SHA256SUMS` file among the release files.

## Changed

- A Kobo's EPUB is named `.kepub.epub`, as Kindle Comic Converter names it. A loose CBZ takes its cover from a `Covers` folder beside it.
- Converting some titles of a library binds only those, not the whole library first.
- Saving to a FAT or exFAT drive needs room for the book once, not twice.
- Saving volumes keeps the other keys of `mangabind.json`. A file that is not valid JSON is refused, not overwritten.
- The validated plan names the books the run will really make.
- Cancel stops the item that is running. A question that opens in place takes keyboard focus. A screen reader hears one message for each tenth of the work, not one for each page.

## Fixed

- Two copies of one chapter: the editor refuses to place one (mangabind skips all copies), and the results say what a book lacks.
- A title over 200 bytes, or an option out of range (gamma `18` for `1.8`), is refused at the start. One bad value no longer drops all the saved options.
- Number fields: clearing one and typing `2` gives `2`, not `12`. A decimal comma is accepted.
- Sharing: Stop sharing ends the downloads in progress, an idle connection is dropped after a minute, quitting does not wait for a stalled download, and a malformed address is not found instead of an error. A title with a character XML forbids no longer breaks the catalog.
- What a killed run left behind is cleared at the next start.
- Names that differ only in how an accent is written are no longer taken for different ones.
- The window no longer shows a screen for an item that is gone, and an option chosen before the saved ones had loaded is kept.

## Security

- A link in a manga folder is followed only if it leads to a file inside it (mangabind 0.6.1).
- The share answers only to an address of your computer (the numbers the app shows, `localhost`, the computer's name), so a web page cannot reach it through your browser.
- The window loads from the app's own address, talks only to the app and has only the permissions it uses. One copy of the app runs at a time.
