# Mangabound v0.1.0-alpha.1

Mangabound is a desktop app that turns manga you already have — folders of chapters, or `.cbz` files — into books ready for your e-reader.

**This is an alpha.** It works, and the core flow (add files or folders, group them into volumes, convert, save or share) is tested end to end against the real bundled tools on every supported platform. Expect rough edges elsewhere: no auto-update yet, and the installers below aren't code-signed. See "Known limitations" below before you install.

## Supported platforms

| Platform                         | File to download                            | Notes                                                |
| -------------------------------- | ------------------------------------------- | ---------------------------------------------------- |
| Windows x64                      | `Mangabound-0.1.0-alpha.1.Setup.exe`        |                                                      |
| macOS, Apple Silicon             | `Mangabound-darwin-arm64-0.1.0-alpha.1.zip` | Intel Macs are not built or tested for this release. |
| Linux, Debian/Ubuntu family, x64 | `mangabound_0.1.0~alpha.1_amd64.deb`        |                                                      |
| Linux, Fedora/RHEL family, x64   | `mangabound-0.1.0.alpha.1-1.x86_64.rpm`     |                                                      |

No Arch/AUR package and no AppImage for this release — see "Known limitations."

## Installing

**Windows:** download `Mangabound-0.1.0-alpha.1.Setup.exe` and run it. See "Security prompts" below — the installer isn't code-signed, so Windows will say something about it.

**macOS (Apple Silicon):** download the `.zip`, unzip it, and drag `Mangabound.app` to your Applications folder. See "Security prompts" below before your first launch — the app isn't signed or notarized, so macOS will block it by default.

**Debian, Ubuntu, and derivatives:** download the `.deb` and install it with your usual tool, for example:

```text
sudo apt install ./mangabound_0.1.0~alpha.1_amd64.deb
```

**Fedora, RHEL, and derivatives:** download the `.rpm` and install it with your usual tool, for example:

```text
sudo dnf install ./mangabound-0.1.0.alpha.1-1.x86_64.rpm
```

## Security prompts

Neither installer is code-signed or notarized yet — that's tracked as future work, not an oversight. Here's what that means at install time, factually, without exact dialog wording we haven't confirmed on the real downloaded file yet:

- **Windows** will flag the installer as coming from an unrecognized publisher, through Windows Defender SmartScreen. There's a way to proceed past that warning and continue the install; the exact click path will be confirmed and added here once verified against this release's actual downloaded `.exe`, not assumed from general SmartScreen behavior.
- **macOS** will likely refuse to open the app on its first launch, since it's from an unidentified developer and isn't notarized. There is a way to allow it — through System Settings, since recent macOS versions vary in whether a simple right-click-Open still works — but the exact confirmed steps for this release aren't written here yet; they'll be added once verified against the real downloaded `.zip`, not assumed.
- **Linux** installs through `.deb`/`.rpm` are not expected to hit anything equivalent.

We won't tell you to turn off SmartScreen, Gatekeeper, or any other OS protection system-wide — only how to allow this one app once you've decided to trust it.

## What's bundled

Mangabound carries two small, pinned command-line tools inside it — nothing is downloaded after install:

- **[mangabind](https://github.com/gustavommcv/mangabind) v0.4.0** — groups chapters into volumes.
- **[mangapress](https://github.com/gustavommcv/mangapress) v0.5.0** — converts a volume for your e-reader.

Both are checksum-verified at build time and again the first time the app runs.

## Known limitations for this alpha

- **No auto-update.** You'll need to download and install each new release yourself.
- **No code signing or notarization**, on any platform — see "Security prompts" above.
- **macOS: Apple Silicon only.** No Intel Mac build.
- **No Arch/AUR package.** Not planned for this alpha; may follow later.
- **No AppImage.** Investigated for this release and deliberately deferred — AppImages of Electron apps commonly fail to launch under their sandbox on many systems, for reasons specific to the AppImage format itself, and a proper fix needs its own dedicated work rather than a first-alpha workaround.

## Reporting a problem

Please [open an issue](https://github.com/gustavommcv/mangabound/issues) — include your OS, what you were trying to do, and what happened instead. For a crash or a conversion that failed, the exact error message helps a lot.
