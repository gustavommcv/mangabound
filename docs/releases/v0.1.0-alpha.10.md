# Mangabound v0.1.0-alpha.10

Mangabound is a desktop app that turns manga you already have — folders of chapters or `.cbz` files — into books ready for your e-reader.

**This is an alpha.** There is no auto-update yet, and the installers are not code-signed. See "Known limitations" before installing.

**If you share a folder over the network with KOReader, please update:** this release fixes a flaw in sharing that is present in v0.1.0-alpha.9 and every earlier release.

## What's new since v0.1.0-alpha.9

- **A fix for the network sharing, which could send a file from outside the shared folder.** In alpha.9 and earlier, a folder's catalog (`.mangabound/library.json`) could name a file outside the shared folder, and the sharing server would send it to whoever asked for it. A link (a symlink or a junction) inside the folder could lead out the same way. Both are closed: the server now sends only files that are really inside the folder you chose. Reaching the flaw took a folder with a catalog or links that someone else made, that you then shared, and a device on your network (with the password, if you set one), so it was unlikely, but the file would have been read with your own permissions. One consequence: a subfolder that is a link to another place, such as another disk, is no longer shared. Share the folder the books really live in instead; the app's log says which book was left out.
- **Errors say what really failed.** A full drive, or a file or folder the app was not allowed to use, used to be reported as "the sharing server could not be started". They now say that a file or folder could not be used, or that the drive is full, and the real cause is written to the app's log.
- **Saving the catalog, the settings and the record of saved books is more careful.** They are written to a temporary file beside the real one and then put in place, and the app tries again for a moment if another program, such as an antivirus, is holding the file.
- **A title or an author that starts with a hyphen no longer stops the conversion.** `-Hidden Title` used to end with a message about invalid arguments.
- **A book whose title starts with dots can be saved to a library.** `...And so on` used to fail with "not inside the selected library".
- **The title bar no longer says "Desktop".**

Behind the scenes the app's main screen was split into smaller parts, and the build tools were brought up to date. There is nothing to do about either.

## Installing

**Windows:** download `Mangabound-0.1.0-alpha.10.Setup.exe` and run it. The installer is not code-signed, so Windows may identify it as coming from an unrecognized publisher. If you prefer not to run an installer, download the portable `.zip`, unzip it, and run `mangabound.exe` directly.

**macOS (Apple Silicon):** download the `.zip`, unzip it, and drag `Mangabound.app` to your Applications folder. The app is not signed or notarized, so macOS may block its first launch.

**Debian, Ubuntu, and derivatives:** download the `.deb` and install it with your usual tool, for example:

```text
sudo apt install ./mangabound_0.1.0.alpha.10_amd64.deb
```

**Fedora, RHEL, and derivatives:** download the `.rpm` and install it with your usual tool, for example:

```text
sudo dnf install ./mangabound-0.1.0.alpha.10-1.x86_64.rpm
```

**Arch, and derivatives:** download the `.pkg.tar.zst` and install it with pacman, for example:

```text
sudo pacman -U ./mangabound-0.1.0_alpha.10-1-x86_64.pkg.tar.zst
```

This is a direct download built by this project's CI, not a submission to the AUR. Pacman resolves the app's runtime dependencies from your usual repositories.

## Security prompts

The Windows installer is not code-signed, and the macOS app is not signed or notarized. Both operating systems may show a security warning; do not disable either operating system's protection globally.

The published files of this release were **not** downloaded and opened by hand after publishing, so the exact prompts are still not documented. What was checked is what the project's CI does for every change: the installers are built on Windows, macOS and Linux, the packaged app is run on all three systems, including under Wayland, and the `.deb` and the Arch package are installed and launched with the sandbox on. That last step only reports what it saw and never fails a build, and a launch does not show that a conversion works: see the audit of 2026-10-04 (finding P3-01) for what it missed.

## What's bundled

Mangabound includes two pinned command-line tools; nothing is downloaded after installation:

- **[mangabind](https://github.com/gustavommcv/mangabind) v0.6.0** — groups chapters into volumes, can bind the whole series into one `.cbz` for conversion, and reports how many pages it has copied.
- **[mangapress](https://github.com/gustavommcv/mangapress) v0.6.0** — converts for your e-reader and builds the nested EPUB table of contents.

Both are checksum-verified at build time, and again every time the app starts.

## Known limitations

- Combining the whole series into one book supports EPUB only, not CBZ or PDF.
- The author is written into EPUB and PDF books only; a CBZ carries no author.
- Pending books are local to this app installation and are not a permanent backup. Keep exported files in a safe location. Once a completed run has been closed and cleaned up, or explicitly deleted, deleted exports require reprocessing.
- A subfolder of a shared folder that is a link to a place outside it is not shared.
- No automatic updates; download and install each new release manually.
- No code signing or notarization on any platform, and no checksum file or build attestation is published with the files yet.
- macOS builds support Apple Silicon only, not Intel Macs.
- No AppImage in this alpha.
- The Arch package is a direct download; there is no AUR submission yet.
