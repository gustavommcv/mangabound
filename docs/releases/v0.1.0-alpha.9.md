# Mangabound v0.1.0-alpha.9

Mangabound is a desktop app that turns manga you already have — folders of chapters or `.cbz` files — into books ready for your e-reader.

**This is an alpha.** There is no auto-update yet, and the installers are not code-signed. See "Known limitations" before installing.

## What's new since v0.1.0-alpha.8

- **Books with the same name never replace each other.** Two books that ended up with the same file name in one run, for example two `Vol.01.cbz` from different folders, used to overwrite each other silently. Now each one is kept, the later ones as `Name (2)`, and the same rule applies when saving into a folder that already holds a file of that name.
- **Title, author and language for each book, on its own page.** Every item in the queue, and every title of a library, has a new button that opens a page for that book alone. A series is named `<Title> - Vol.NN` per volume; a single book uses the title as typed. Title and author are gone from the advanced options, where they applied to every book of the run at once. The EPUB language option stays there as the default, and each book can override it.
- **Find the author online, only when you ask.** On that page, "Find author" searches an online source for the title you typed and lets you pick the author. You choose the source at that moment; nothing is chosen for you and nothing is sent until you click. If nothing matches, the page says so and points at the title, since extra characters in a folder name are the usual reason. Every online request now gives up after 15 seconds instead of waiting forever.
- **The author and language stay with the folder.** They are saved in the folder's `mangabind.json`, so adding the same folder, or a library, next time brings them back. Only those two keys are written; the rest of that file is left as it was, and mangabind ignores them. If the folder cannot be written to, a notice says so and the details stay for the session.

## Installing

**Windows:** download `Mangabound-0.1.0-alpha.9.Setup.exe` and run it. The installer is not code-signed, so Windows may identify it as coming from an unrecognized publisher. If you prefer not to run an installer, download the portable `.zip`, unzip it, and run `mangabound.exe` directly.

**macOS (Apple Silicon):** download the `.zip`, unzip it, and drag `Mangabound.app` to your Applications folder. The app is not signed or notarized, so macOS may block its first launch.

**Debian, Ubuntu, and derivatives:** download the `.deb` and install it with your usual tool, for example:

```text
sudo apt install ./mangabound_0.1.0.alpha.9_amd64.deb
```

**Fedora, RHEL, and derivatives:** download the `.rpm` and install it with your usual tool, for example:

```text
sudo dnf install ./mangabound-0.1.0.alpha.9-1.x86_64.rpm
```

**Arch, and derivatives:** download the `.pkg.tar.zst` and install it with pacman, for example:

```text
sudo pacman -U ./mangabound-0.1.0_alpha.9-1-x86_64.pkg.tar.zst
```

This is a direct download built by this project's CI, not a submission to the AUR. Pacman resolves the app's runtime dependencies from your usual repositories.

## Security prompts

The Windows installer is not code-signed, and the macOS app is not signed or notarized. Both operating systems may show a security warning. We will document the exact prompts and per-app steps after testing the published files; do not disable either operating system's protection globally.

## What's bundled

Mangabound includes two pinned command-line tools; nothing is downloaded after installation:

- **[mangabind](https://github.com/gustavommcv/mangabind) v0.6.0** — groups chapters into volumes, can bind the whole series into one `.cbz` for conversion, and reports how many pages it has copied.
- **[mangapress](https://github.com/gustavommcv/mangapress) v0.6.0** — converts for your e-reader and builds the nested EPUB table of contents.

Both are checksum-verified at build time and again the first time the app runs.

## Known limitations

- Combining the whole series into one book supports EPUB only, not CBZ or PDF.
- The author is written into EPUB and PDF books only; a CBZ carries no author.
- Pending books are local to this app installation and are not a permanent backup. Keep exported files in a safe location. Once a completed run has been closed and cleaned up, or explicitly deleted, deleted exports require reprocessing.
- No automatic updates; download and install each new release manually.
- No code signing or notarization on any platform.
- macOS builds support Apple Silicon only, not Intel Macs.
- No AppImage in this alpha.
- The Arch package is a direct download; there is no AUR submission yet.

Please [open an issue](https://github.com/gustavommcv/mangabound/issues) and include your operating system, what you were trying to do, and what happened. For a crash or failed conversion, include the exact error message.
