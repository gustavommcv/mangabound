**`mangabind`** is a standalone, dependency-free CLI utility written in Go. Its sole responsibility is inspecting unstructured chapter directories or loose chapter `.cbz` files and organizing them into consolidated, numbered volume `.cbz` archives containing standard `ComicInfo.xml` metadata.

---

## Installation & Binary Location

In a standard Mangabound desktop installation, `mangabind` is bundled internally under the application's runtime directories.

To use `mangabind` standalone:
* Download the compiled binary directly from [github.com/gustavommcv/mangabind/releases](https://github.com/gustavommcv/mangabind/releases).
* Place it in your system's `PATH` (e.g. `/usr/local/bin` on Linux/macOS or `C:\Windows\System32` on Windows).

---

## Command-Line Usage

```bash
mangabind [options] --input <path> --output <path>
```

### Essential Flags

| Flag | Short | Description |
|---|---|---|
| `--input <path>` | `-i` | Path to the directory containing raw chapter folders or `.cbz` files. |
| `--output <path>` | `-o` | Destination directory where finished volume `.cbz` files will be written. |
| `--dry-run` | `-n` | Simulates chapter parsing and volume grouping without modifying the disk. |
| `--batch` | `-b` | **Library Mode**: Treats each immediate subfolder as an independent manga series. |
| `--metadata-file <path>` | | Explicit path to a `mangabind.json` volume mapping manifest. |
| `--json` | | Emits the complete machine-readable report to `stdout`. |
| `--quiet` | `-q` | Suppresses non-essential terminal logging; errors and warnings remain visible. |
| `--protocol-version` | | Returns the Machine Protocol v1 handshake JSON. |
| `--version` | | Prints the binary version string. |
| `--help` | `-h` | Displays the help text. |

## Practical Examples

### 1. Dry-Run Planning with JSON Output
Inspect a series folder without creating any archives:
```bash
mangabind --input "./Chainsaw Man" --output "./Volumes" --dry-run --json
```

### 2. Standard Volume Bundling
Bundle chapters into volumes, writing resulting `.cbz` files:
```bash
mangabind --input "./Frieren" --output "./Ready_Volumes"
```

### 3. Batch Library Processing
Process an entire library folder with dozens of manga series in one command:
```bash
mangabind --input "/mnt/storage/MangaLibrary" --output "/mnt/storage/BundledVolumes" --batch
```

## The `mangabind.json` Format

If chapters lack volume tags in their folder names, place a `mangabind.json` file inside the manga directory:

```json
{
  "schema_version": 1,
  "volumes": [
    { "number": "1", "chapters": ["1-7"] },
    { "number": "2", "chapters": ["8-16", "8.5"] }
  ]
}
```

* Supports inclusive integer ranges (`"1-7"`).
* Supports specific chapters and fractional chapters (`"8.5"`).
* Explicit volume names inside filenames always take precedence over `mangabind.json`.
