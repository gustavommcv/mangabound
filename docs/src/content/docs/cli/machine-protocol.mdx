Mangabound does not scrape human-readable terminal text. Instead, both `mangabind` and `mangapress` implement the **Machine Protocol v1** specification, establishing a typed, backwards-compatible inter-process communication (IPC) channel via standard streams.

---

## 1. Handshake & Capability Discovery

Before launching any job, Mangabound queries the tool version and capabilities:

```bash
mangabind --protocol-version
mangapress --protocol-version
```

### Response Example (`stdout`, Exit Code 0)
```json
{
  "protocol_version": 1,
  "tool": "mangapress",
  "tool_version": "0.6.0",
  "sequence": 1,
  "type": "protocol",
  "capabilities": ["events", "profiles"]
}
```

If the protocol version does not match the expected major version, Mangabound safely halts execution with an explanatory error.

---

## 2. `mangabind` Batch Report Format

When executing with `--json`, `mangabind` outputs a complete structured document on completion:

```json
{
  "protocol_version": 1,
  "mode": "plan",
  "units": [
    {
      "path": "Ch.01",
      "kind": "folder",
      "effective_volume": "1",
      "page_count": 22,
      "disposition": "included"
    }
  ],
  "volumes": [
    {
      "number": "1",
      "filename": "Manga - Vol.01.cbz",
      "estimated_pages": 190,
      "sources": ["Ch.01", "Ch.02", "Ch.03"]
    }
  ],
  "issues": []
}
```

* `mode`: Either `"plan"` (when called with `--dry-run`) or `"execute"`.
* `issues`: Structured warnings and errors (e.g. `chapter_gap`, `unassigned_chapter`).

## 3. `mangapress` JSON Lines Streaming

Because image conversion can take minutes for large books, `mangapress` emits continuous **UTF-8 JSON Lines** (one valid JSON object per line) on `stdout`:

```json
{"type": "stage", "stage": "inspect", "state": "started"}
{"type": "stage", "stage": "inspect", "state": "completed"}
{"type": "stage", "stage": "process", "state": "started"}
{"type": "chapter", "chapter_index": 1, "source_pages": 24}
{"type": "page", "completed": 1, "total": 180, "page": 1, "chapter": "Ch. 1"}
{"type": "page", "completed": 2, "total": 180, "page": 2, "chapter": "Ch. 1"}
{"type": "stage", "stage": "package", "state": "started"}
{"type": "result", "bytes": 14205810, "path": "/path/output.epub", "duration_ms": 4210}
```

This streaming protocol powers Mangabound's smooth, real-time page progress bar.
