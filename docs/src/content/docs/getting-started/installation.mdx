Mangabound is available as pre-built native binaries across Windows, macOS, and Linux. Each build embeds certified releases of **mangabind** and **mangapress**, requiring zero external runtime setup.

Download the latest package for your operating system from the [official GitHub Releases](https://github.com/gustavommcv/mangabound/releases/latest).

---

## Operating System Packages

<Tabs>
  <TabItem label="Windows">
    ### Windows (x64)
    Choose between the setup installer or the standalone portable package:

    * **Installer (`.exe`)**: Recommended for most users. Run `mangabound-Setup-<version>.exe` and follow the on-screen prompts.
    * **Portable (`.zip`)**: Extract `mangabound-win32-x64-<version>.zip` anywhere on your drive and run `mangabound.exe`. Useful for USB drives and environments without administrator permissions.

    :::note[Windows SmartScreen]
    During alpha releases, installers are not yet code-signed with an expensive EV certificate. Windows SmartScreen may present a warning. Click **More info** > **Run anyway** to proceed.
    :::
  </TabItem>

  <TabItem label="macOS">
    ### macOS (Apple Silicon - M1/M2/M3/M4)
    * Download `mangabound-darwin-arm64-<version>.zip`.
    * Unzip the archive and drag `Mangabound.app` into your `/Applications` folder.

    :::note[macOS Gatekeeper]
    Because alpha binaries are self-published without notarization, macOS Gatekeeper may display a message stating the app cannot be opened.
    
    To authorize it:
    1. Right-click (or Control-click) `Mangabound.app` in Finder and select **Open**.
    2. Click **Open** in the confirmation dialog.
    Alternatively, allow it in **System Settings** > **Privacy & Security**.
    :::
  </TabItem>

  <TabItem label="Linux">
    ### Linux (x64)
    Mangabound provides native packages for the most popular Linux distributions:

    #### Debian / Ubuntu / Mint / Pop!_OS (`.deb`)
    ```bash
    sudo dpkg -i mangabound_<version>_amd64.deb
    # If missing any standard system dependencies:
    sudo apt-get install -f
    ```

    #### Fedora / RHEL / openSUSE (`.rpm`)
    ```bash
    sudo rpm -i mangabound-<version>.x86_64.rpm
    ```

    #### Arch Linux / Manjaro (`.pkg.tar.zst`)
    ```bash
    sudo pacman -U ./mangabound-<version>-x86_64.pkg.tar.zst
    ```
  </TabItem>
</Tabs>

## Toolchain Verification

Mangabound guarantees absolute security and reproducibility when invoking internal tools.

Every build contains a strictly locked [`toolchain.lock.json`](https://github.com/gustavommcv/mangabound/blob/main/toolchain.lock.json) specification. When Mangabound launches or prepares a conversion job:
1. It verifies the **SHA-256 cryptographic hash** of the bundled `mangabind` and `mangapress` executables.
2. Any tampered or corrupted binary is rejected immediately before execution.
3. Version and protocol handshakes (`--protocol-version`) are run to confirm IPC protocol compatibility.
