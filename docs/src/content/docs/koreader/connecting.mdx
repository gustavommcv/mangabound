First [start sharing in Mangabound](../opds-sharing/), and connect your reader to the same reachable local network.

1. In KOReader's file browser, open **OPDS catalog** from the search menu. Menu wording can vary with KOReader version and language.
2. Add a catalog named **Mangabound**. Paste the exact address shown by the app. Supply the username/password only if you set them in Mangabound.
3. Open the catalog and choose **Recently converted** to find the books you just processed, newest first. **Other files** lists untracked books in a shared library.
4. Choose a book and download it to a folder on your reader. Open the downloaded file with KOReader.

<MediaSlot id="reader-catalog" />

Once downloaded, the book is local to your reader. Mangabound does not need to remain open for reading—only for further downloads. If the computer's address stays the same, the catalog can be reused next time you enable sharing.

For connection problems, see the [sharing checklist](../opds-sharing/#if-your-reader-cannot-connect). For display settings, see [KOReader settings](../recommended-settings/).
