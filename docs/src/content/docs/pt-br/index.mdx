# Mangabound

O **Mangabound** é um aplicativo desktop que transforma mangás que você já possui, como pastas de capítulos ou arquivos CBZ, em livros digitais prontos para o seu e-reader.

## O que ele faz

1. **Adicionar**: Arraste pastas de mangá, bibliotecas inteiras ou arquivos `.cbz` para a fila.
2. **Conferir Volumes**: Se os nomes já contiverem o número do volume (`Vol.01 Ch.001`), os capítulos já vêm agrupados. Caso contrário, o editor visual de mapeamento busca a contagem oficial no **MangaDex** ou permite organizar manualmente com suporte a desfazer/refazer.
3. **Escolher o Processo**: Reagrupar em CBZ, converter para e-reader ou ambos. Escolha o dispositivo alvo (**Kindle**, **Kobo**, **reMarkable**) e formato (**EPUB**, **CBZ**, **PDF**).
4. **Processar**: A conversão exibe progresso contínuo página a página com cancelamento instantâneo seguro.
5. **Salvar ou Compartilhar**: Salve volumes individuais, exporte a série inteira em lote ou compartilhe pela rede Wi-Fi diretamente para o **KOReader** via catálogo OPDS.

## O Ecossistema

O Mangabound é uma interface visual que orquestra duas ferramentas autônomas de linha de comando:

* **[mangabind](https://github.com/gustavommcv/mangabind)**: Agrupa capítulos em arquivos `.cbz` por volume com metadados `ComicInfo.xml`.
* **[mangapress](https://github.com/gustavommcv/mangapress)**: Redimensiona, ajusta contraste, recorta margens e divide páginas duplas em Rust com alta performance.
