## 1. Adicione seu mangá

Arraste uma pasta de mangá ou CBZ para a fila ou use **Files** ou **Folder**. Você também pode clicar nessa área para escolher os arquivos.

Uma pasta contém capítulos separados. Um CBZ avulso é tratado como volume completo; para CBZs de capítulos individuais, adicione a pasta que os contém.

<MediaSlot id="quickstart-add" />

## 2. Confira os volumes

Para uma pasta de capítulos, use **Edit volumes** para conferir a organização.

- **File names** resume os volumes já reconhecidos nos nomes.
- **Manual** permite criar volumes e atribuir capítulos selecionados ou um intervalo.
- **Online source** busca opcionalmente uma sugestão no MangaDex. Confira o resultado antes de confirmar.

Se nenhum volume for reconhecido, o editor abre **Manual** com uma explicação. Você pode organizar tudo offline, sem uma obra cadastrada online. Veja o passo a passo em [organização de volumes](../../user-guide/mapping-editor/).

## 3. Escolha dispositivo e formato

Em **Steps**, mantenha **Group chapters into volumes** e **Convert for e-reader** ativados para executar ambas as etapas. Selecione **Device** e **Format**. Use **Advanced conversion options** apenas se precisar alterar os ajustes de imagem.

Quer a série inteira em um único livro? Ative **Create one book for the series**. Esse modo usa EPUB e mantém as duas etapas ativadas. Desative-o para mudar o formato ou as etapas.

## 4. Processe

Clique em **Process** ou **Process N items**, conforme a fila. O aplicativo mostra o progresso geral; **Show details** exibe o progresso dos volumes quando disponível. Livros maiores demoram mais, e o salvamento pode continuar depois do processamento das páginas.

## 5. Salve ou compartilhe

Use **Save as…** ao lado de um livro ou **Save all to folder…** para vários. Enquanto os livros pendentes estiverem disponíveis, você pode salvar novamente em outro destino sem reconverter.

**Share these books** permite que o KOReader os baixe pela rede local, mesmo antes de exportar uma cópia. Siga o [guia de compartilhamento](../../koreader/opds-sharing/).

<MediaSlot id="quickstart-save" />

:::note[Não descarte sua única cópia]
Livros prontos ainda não salvos continuam em **Ready books** após reiniciar o app. **Delete** remove os livros pendentes de uma conversão, não apenas sua linha. Salve primeiro o que quiser preservar. [Como salvar e excluir](../../user-guide/exporting/).
:::
