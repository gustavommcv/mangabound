O Mangabound não realiza raspagem de texto livre no terminal. Em vez disso, o `mangabind` e o `mangapress` implementam a especificação **Machine Protocol v1**, criando um canal tipado e retrocompatível de comunicação entre processos via `stdin`/`stdout`.

---

## 1. Handshake e Descoberta de Recursos

Antes de disparar qualquer processamento, o Mangabound confere a versão e as capacidades de cada ferramenta:

```bash
mangabind --protocol-version
mangapress --protocol-version
```

### Exemplo de Resposta (`stdout`, Código de Saída 0)
```json
{
  "protocol_version": 1,
  "tool": "mangapress",
  "tool_version": "0.6.0",
  "sequence": 1,
  "type": "protocol",
  "capabilities": ["events", "profiles"]
}
```

Se a versão maior do protocolo não for compatível, a execução é interrompida com segurança e mensagem clara.

---

## 2. Relatório Estruturado do `mangabind`

Ao rodar com `--json`, o `mangabind` devolve um documento JSON completo ao final da execução:

```json
{
  "protocol_version": 1,
  "mode": "plan",
  "units": [
    {
      "path": "Ch.01",
      "kind": "folder",
      "effective_volume": "1",
      "page_count": 22,
      "disposition": "included"
    }
  ],
  "volumes": [
    {
      "number": "1",
      "filename": "Manga - Vol.01.cbz",
      "estimated_pages": 190,
      "sources": ["Ch.01", "Ch.02", "Ch.03"]
    }
  ],
  "issues": []
}
```

* `mode`: `"plan"` (ao rodar com `--dry-run`) ou `"execute"`.
* `issues`: Avisos estruturados sobre lacunas (`chapter_gap`) ou duplicidades.

---

## 3. Streaming JSON Lines do `mangapress`

Como a conversão de imagens de um volume inteiro pode levar minutos, o `mangapress` emite uma corrente contínua em **JSON Lines** (um objeto JSON por linha) no `stdout`:

```json
{"type": "stage", "stage": "inspect", "state": "started"}
{"type": "stage", "stage": "inspect", "state": "completed"}
{"type": "stage", "stage": "process", "state": "started"}
{"type": "chapter", "chapter_index": 1, "source_pages": 24}
{"type": "page", "completed": 1, "total": 180, "page": 1, "chapter": "Ch. 1"}
{"type": "page", "completed": 2, "total": 180, "page": 2, "chapter": "Ch. 1"}
{"type": "stage", "stage": "package", "state": "started"}
{"type": "result", "bytes": 14205810, "path": "/path/output.epub", "duration_ms": 4210}
```

É esse fluxo contínuo que alimenta a barra de progresso suave página a página na interface do Mangabound.
