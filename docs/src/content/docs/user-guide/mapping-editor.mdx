One of the most frequent challenges when preparing digital manga collections is inconsistent chapter naming. Scanlation groups often name releases simply as `Chapter 01`, `Chapter 02`, without indicating which physical volume they belong to.

The **Volume Mapping Editor** solves this problem by allowing you to inspect, group, and split chapters with visual confidence.

---

## Anatomy of the Editor

The editor displays two main columns:

1. **Volume Tree (Assigned Volumes)**: Shows each created volume (e.g. `Volume 1`, `Volume 2`), its estimated total page count, and the chapters nested inside.
2. **Unassigned Chapters**: Lists any chapters that were discovered without an explicit volume tag.

## Grouping Methods

You have three powerful ways to map your chapters:

### 1. Online Lookup via MangaDex
This is the fastest method for popular series:
<Steps>
1. Click the **From MangaDex** button at the top of the editor.
2. Enter the official series title (e.g. *Chainsaw Man* or *Frieren*).
3. Select the matching entry from the search results.
4. Mangabound pulls the official volume-to-chapter index from MangaDex's public API and automatically sorts all loose chapters into their canonical volumes.
</Steps>

:::note[Privacy & API Compliance]
Mangabound only queries the MangaDex metadata API for chapter numbers and volume counts. It never downloads images or uploads your personal files.
:::

### 2. Auto-Assign
If you are working offline, click **Auto-Assign**. Mangabound runs local heuristic pattern matching to detect volume signals inside folder names (e.g., tags like `[v01]`, `Vol. 1`, or common chapter count intervals).

### 3. Manual Editing & Fine-Tuning
You have full granular control over every chapter:
* **Drag and Drop**: Drag chapters between volumes or move them back to the unassigned list.
* **Add Volume**: Click **Add Volume** to instantiate Volume `N+1`.
* **Merge Volumes**: Combine adjacent volumes into a single omnibus volume.
* **Undo & Redo**: Mistakes happen! Use the `Undo` (`Ctrl+Z` / `Cmd+Z`) and `Redo` buttons to step backwards and forwards through your editing history.

## The `mangabind.json` File

When you finish organizing your chapters, Mangabound serializes your decisions into a standardized `mangabind.json` manifest:

```json
{
  "schema_version": 1,
  "volumes": [
    { "number": "1", "chapters": ["1-7"] },
    { "number": "2", "chapters": ["8-16", "8.5"] }
  ]
}
```

Because `mangabind` adheres to the [CLI-First Principle](../../getting-started/overview/#1-the-cli-first-rule), this file is completely portable. You can copy this `mangabind.json` file into the manga's folder on any machine and run `mangabind` directly via terminal to reproduce the exact same volume packaging!
